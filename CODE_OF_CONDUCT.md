# Code of Conduct

Brainwaves is a welcoming project. We expect everyone who takes part to:

- be respectful, patient and constructive, especially in disagreements about evidence;
- criticise ideas and claims, not people;
- respect privacy, and never share another person's personal or health information;
- use inclusive language;
- accept that maintainers may remove comments or contributions that harass, demean or mislead.

Report concerns privately to the maintainers through GitHub, using the contact on the repository owner's profile. Reports are handled confidentially.

This code was written for this project. It is informed by widely used community norms, such as the Contributor Covenant (https://www.contributor-covenant.org).
